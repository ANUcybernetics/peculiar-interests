# Peculiar Interests

An open, versioned dataset and website of the registers of interests of
Australian federal parliamentarians: what every MP and senator has declared they
own, owe and were given, read from the official House and Senate registers into
one schema, kept current nightly, and published with a static JSON/CSV API.

A _Cybernetic Studio_ project by [Ben Swift](https://benswift.me), and a sibling
of the [Australian Government AI Tracker](https://apsaitracker.app).

## How it works

- **Senate**: the register's web app is backed by a JSON data service;
  `pollie fetch senate` saves every senator's statement as returned and
  `pollie parse senate` maps it field for field into the schema.
- **House**: the register index links one PDF per member. Most are generated by
  the registrar's form system and their tables are read exactly from the text
  layer with pdfplumber, no model involved. A few members lodge handwritten
  scans; `pollie transcribe` hands their page images to Claude (through
  `claude -p`, on the subscription, no API key) to produce an override that a
  person checks against the PDF before it is shown as confirmed.
- **Roster**: APH's own member and senator CSVs supply party, gender and
  electorate; both chambers share the APH person id, which is the key
  throughout.
- Raw fetches are committed under `raw/` as evidence; `data/` holds one
  `Statement` JSON per person per parliament and is regenerated from `raw/` by
  the parsers, so `git log data/` is the history of what the register said.
- The Astro site under `site/` reads `data/` at build time and publishes pages
  per person, per item, per named company or organisation, a ledger of every
  alteration, search, and the static API at `/api/v1/`.

```sh
mise exec -- uv run pollie run      # fetch, parse, roster, schema, status
mise exec -- uv run pollie status   # what we hold; which scans still need a person
cd site && mise exec -- pnpm dev    # the site, live
```

See `CLAUDE.md` for the layout and the source endpoints, `PRODUCT.md` and
`DESIGN.md` for the site's intent.

## Contributing

If an entry here does not match the official document, open an issue or email
[ben.swift@anu.edu.au](mailto:ben.swift@anu.edu.au) with the person's name and
what is wrong. Corrections to a scanned statement go in `overrides/` (see
`src/pollie_watch/overrides.py` for the format).
