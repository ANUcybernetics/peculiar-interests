# Peculiar Interests

An open, versioned dataset and website of the registers of interests of
Australian federal parliamentarians (House of Representatives and Senate).

A _Cybernetic Studio_ project by [Ben Swift](https://benswift.me). Work in
progress; see `CLAUDE.md` for the layout and sources.
